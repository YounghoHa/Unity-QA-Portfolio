# QA Case — Card Combination to Merge

## Initial Planning

서로 다른 원소 카드를 조합하여 새로운 카드를 만드는 시스템을 기획했습니다.

목표는 다양한 조합을 통해 전략성과 게임의 차별성을 만드는 것이었습니다.

예시:

Fire + Water → 새로운 조합 카드

## Play Test

기능 구현 자체는 가능했지만 플레이 과정에서 다음 문제가 확인되었습니다.

- 원하는 결과를 얻기 위해 조합식을 기억해야 함
- 카드 종류가 늘어날수록 학습 부담 증가
- 플레이어가 조합 결과를 직관적으로 예상하기 어려움
- 새로운 조합마다 추가 카드 데이터와 아트 리소스가 필요

## Result

**Functional PASS / Planning FAIL**

기능은 정상적으로 구현 가능했지만, 실제 플레이에서는 전략적인 판단보다 조합식 암기 부담이 커질 가능성이 있다고 판단했습니다.

## Improvement

서로 다른 카드 조합 방식 대신 **동일 카드 Merge 방식**으로 변경했습니다.

동일 카드 + 동일 카드  
→ 상위 카드

## Expected Improvement

- 규칙 이해가 쉬움
- 결과 예측 가능
- 카드 성장 목표가 명확함
- 기존 카드 리소스를 활용 가능
- 콘텐츠 추가 비용 감소

## QA Value

기능 구현 성공 여부가 아니라 실제 플레이 경험과 기획 목적을 기준으로 시스템 변경을 제안하고 검증한 사례입니다.

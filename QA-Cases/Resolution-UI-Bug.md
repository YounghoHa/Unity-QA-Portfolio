# Bug Report — Resolution / UI Layout

## ID

BUG-UI-01

## Title

해상도 변경 시 UI 레이아웃 깨짐 및 해상도 변경 미적용

## Priority

**Medium**

## Status

**FAIL**

## Issue

게임 옵션에서 해상도를 변경했을 때 UI가 깨지는 문제를 확인했습니다.

게임 내에서는 해상도를 변경하더라도 UI 위치와 크기가 화면 비율에 맞게 유지되어야 합니다.

이후 UI 위치와 크기를 수정하여 레이아웃 깨짐 현상은 보완했지만, 현재 버전에서는 해상도 변경 기능 자체가 정상적으로 적용되지 않고 **1920×1080으로 고정되는 문제**가 남아 있습니다.

따라서 UI 레이아웃 수정 이력은 존재하지만, 해상도 설정 기능 전체 기준으로는 아직 해결되지 않은 상태로 판단하여 **FAIL**을 유지합니다.

## Reproduction Condition

- 옵션 화면 진입 가능
- 해상도 변경 옵션 사용
- 현재 기준 해상도: 1920×1080

## Steps to Reproduce

1. 게임 옵션 화면을 엽니다.
2. 현재 해상도와 다른 해상도를 선택합니다.
3. 해상도 변경을 적용합니다.
4. 실제 게임 화면의 해상도와 UI 배치를 확인합니다.

## Expected Result

- 선택한 해상도가 실제 게임 화면에 적용되어야 합니다.
- 해상도가 변경되어도 UI 위치와 크기가 정상적으로 유지되어야 합니다.
- 화면 비율 변경으로 UI가 잘리거나 위치가 깨지지 않아야 합니다.

## Actual Result

### 1차 확인

- 해상도 변경 시 일부 UI 위치가 깨지는 현상을 확인했습니다.
- UI 위치 / 크기를 수정하여 레이아웃 문제를 보완했습니다.

### 현재 확인

- 해상도 변경 옵션을 사용해도 실제 해상도가 변경되지 않습니다.
- 게임 화면이 1920×1080으로 유지됩니다.
- 따라서 해상도별 UI 레이아웃을 정상적으로 검증할 수 없는 상태입니다.

해당 기록을 통해 해상도 변경 과정에서 UI 레이아웃 문제가 발생했고, 이후 UI 관련 수정이 진행된 이력을 확인할 수 있습니다.

하지만 현재 재검증에서는 해상도 변경 자체가 적용되지 않기 때문에 최종 상태는 PASS로 처리하지 않았습니다.

# Bug Report — Monster Debuff After Death

## ID

BUG-MONSTER-01

## Title

몬스터 처치 후 디버프 공격이 다음 스테이지에서 발동하는 문제

## Priority

**High**

## Status

**FAIL → PASS**

## Issue

플레이어에게 지속적으로 데미지를 주는 디버프 / 공격 효과를 가진 몬스터를 처치한 뒤 다음 스테이지로 이동했을 때, 이미 사망한 몬스터의 능력이 다시 발동하여 플레이어에게 데미지가 들어오는 문제를 확인했습니다.

몬스터가 사망하면 해당 몬스터가 발생시킨 전투용 디버프와 지속 효과도 함께 종료되어야 하며, 다음 스테이지까지 영향을 주면 안 됩니다.

## Reproduction Condition

- 지속 공격 또는 디버프 효과를 사용하는 몬스터와 전투
- 해당 효과가 플레이어에게 적용된 상태
- 몬스터 처치 후 다음 스테이지로 이동 가능

## Steps to Reproduce

1. 지속 공격 / 디버프 능력을 가진 몬스터와 전투합니다.
2. 몬스터의 능력이 플레이어에게 적용된 상태를 만듭니다.
3. 해당 몬스터를 처치합니다.
4. 전투를 종료하고 다음 스테이지로 이동합니다.
5. 다음 스테이지 진입 후 플레이어 HP 변화를 확인합니다.

## Expected Result

- 몬스터가 사망하면 해당 몬스터가 남긴 공격성 디버프 / 지속 효과가 종료되어야 합니다.
- 다음 스테이지에서는 이전에 처치한 몬스터의 능력이 발동하지 않아야 합니다.
- 플레이어는 이전 몬스터의 효과로 추가 데미지를 받지 않아야 합니다.

## Actual Result

- 몬스터를 처치한 뒤 다음 스테이지로 이동해도 이전 몬스터의 능력이 남아 있었습니다.
- 다음 스테이지에서 해당 효과가 다시 발동하여 플레이어에게 데미지가 들어왔습니다.
- 이미 사망한 몬스터의 전투 상태가 다음 전투까지 영향을 주는 상태였습니다.

## Cause Analysis

몬스터 사망 처리 이후에도 전투 중 적용된 관련 디버프 상태가 정리되지 않아 다음 스테이지까지 유지되는 것이 문제였습니다.

즉, 몬스터 오브젝트의 사망 처리와 플레이어에게 남아 있는 몬스터 기반 디버프 정리가 함께 처리되지 않았습니다.

## Fix

몬스터 사망 처리 시 해당 몬스터의 전투용 디버프 / 지속 효과를 정리하도록 수정했습니다.

이미지에 남아 있는 수정 기록 기준으로는 GameSet에서 몬스터 사망 이후 관련 디버프를 Clear하도록 처리했습니다.

## Retest

수정 후 다음 흐름으로 다시 확인했습니다.

- 몬스터 디버프 적용
- 몬스터 처치
- 다음 스테이지 이동
- 플레이어 HP 변화 확인

수정 후에는 이전 몬스터의 디버프 공격이 다음 스테이지에서 다시 발동하지 않는 것을 확인했습니다.

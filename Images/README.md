# Images / Videos

이 폴더에는 포트폴리오에서 사용하는 실제 게임 화면, Before / After 자료, 버그 재현 영상을 정리합니다.

## Structure

```text
Images/
└── videos/
    ├── Before/
    └── After/
```

- `Before/` : 수정 전 버그 재현 영상
- `After/` : 수정 후 정상 동작 / 회귀 테스트 영상

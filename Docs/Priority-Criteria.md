# Issue Priority Criteria

QA 과정에서 발견한 모든 문제를 동일한 우선순위로 처리하지 않았습니다.

게임 진행에 미치는 영향과 핵심 플레이 경험을 기준으로 우선순위를 구분했습니다.

| Priority | 기준 | 예시 |
|---|---|---|
| High | 핵심 입력, 전투 진행, 데이터 무결성, 게임 규칙을 직접 방해 | 카드 클릭/Drag 불가, 카드 사용 불가, 덱 최대 수량 초과, 잘못된 카드 효과 |
| Medium | 진행은 가능하지만 판단 오류 또는 사용자 혼란을 유발 | Intent와 실제 행동 불일치, 상태 UI 누락, 잘못된 정보 표시 |
| Low | 게임 진행에는 직접 영향이 적은 시각적 문제 | 공격/방어 모션 구분 부족, 일부 VFX 어색함 |

## 판단 사례

### 카드 클릭 / Drag 문제 — High

카드는 플레이어가 전투에서 직접 사용하는 핵심 입력 수단입니다.

카드를 정상적으로 선택하거나 사용할 수 없는 문제는 게임의 핵심 플레이 자체를 방해하기 때문에 최우선 수정 대상으로 판단했습니다.

### 몬스터 공격 / 방어 애니메이션 구분 문제 — Low 또는 Medium

몬스터의 모션만으로 공격과 방어를 구분하기 어려운 문제는 개선이 필요했지만, 체력바 상단 Intent 아이콘으로 다음 행동을 확인할 수 있었습니다.

따라서 카드 입력 문제보다 상대적으로 낮은 우선순위로 판단했습니다.

## 판단 기준

우선순위 판단 시 다음 항목을 함께 확인합니다.

- 진행 차단 여부
- 핵심 게임 규칙 위반 여부
- 플레이어 입력에 직접적인 영향 여부
- 잘못된 판단을 유도하는 정보인지
- 다른 시스템까지 영향을 주는지
- 우회 방법이 존재하는지
